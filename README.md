# multimedia-web

Sitio multimedia de demostración para una actividad universitaria de Git.

Abre index.html en el navegador. No requiere instalaciones ni conexión a Internet.

## Estructura inicial

- index.html: contenido y navegación.
- css/estilos.css: diseño inicial de escritorio.
- images/small, images/medium, images/large: ilustraciones locales en tres resoluciones.
- .gitignore: exclusiones de secretos, dependencias y archivos temporales.
- .gitattributes: configuración de archivos de texto e imágenes.

La rama feature/menu-responsivo incorporará el menú para móviles y la adaptación a tabletas y teléfonos. Las portadas de audio y video son demostrativas.
